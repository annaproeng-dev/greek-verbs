# Карточки A2 — отдельный прототип

Из корня проекта запустите `python3 -m http.server 8766 --bind 127.0.0.1`, затем откройте http://127.0.0.1:8766/prototypes/a2-cards/ . Можно также открыть index.html локально: содержимое загружается через cards-data.js без fetch.

Основное приложение не изменено. Прототип — 58 карточек: 8 тем грамматики по 6 карточек и 10 коммуникативных заданий. Полное сопоставление источников и границы прототипа: ../../docs/learning/a2-textbooks-exam-map.md.

cards.json — переносимые данные; cards-data.js — те же данные для автономного открытия. При редактировании синхронизировать обе версии. Новые карточки должны иметь уникальные стабильные ID. В карточки включены только авторские тексты и библиографические ссылки, без страниц/изображений учебников.

Состояние сохраняется отдельно в localStorage под ключом greek-a2-card-prototype-v1. С основными аккаунтами и статистикой оно не связано. Для сброса удалить только этот ключ.

Озвучка зависит от наличия греческого системного голоса; письмо и речь используют самопроверку. В прототипе нет серверной проверки, записи голоса, адаптации по истории и полноразмерного пробного экзамена.

Проверка: `node verify.cjs` (Node.js, Playwright и Chrome; путь к Playwright в проверке соответствует окружению разработки). Сначала проверяется целостность данных, затем основные действия в браузере.
