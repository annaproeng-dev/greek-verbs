# Карта приложения: A2 → B1 → B2

## Основная логика

Приложение — общий дом для изучения греческого. Глаголы остаются самостоятельным инструментом внутри материалов; они не становятся обязательным входом ко всему обучению.

Уровень — общая настройка пользователя. Его можно выбрать при первом входе и сменить из шапки: A2, B1, B2. Прохождение предыдущего уровня не открывает следующий: все доступны сразу. Базовое правило A2 можно посмотреть из B1/B2 без смены основного уровня. В дальнейшем можно добавить A1/«С нуля» и необязательную диагностику.

## Карта

```text
Первый вход → Выбор уровня: A2 / B1 / B2
                 ↓
Главная выбранного уровня
├── Продолжить / начать тренировку
├── Подготовка к экзамену выбранного уровня
│   ├── Чтение
│   ├── Слушание
│   ├── Письмо
│   └── Говорение
│       Задание ↔ связанное объяснение / словарь
├── Материалы (общая библиотека, фильтр по уровню)
│   ├── Грамматика → тема → объяснение → пример
│   ├── Лексика → ситуация → слово + выражение + контекст
│   └── Глаголы → глагол → формы и примеры
│       Каждая тема → тренировать / практиковать
├── Тренировка — приложение собирает задания
├── Практика — пользователь выбирает содержание, время и формат
└── Мой Кипр
    ├── Результаты по уровням и навыкам
    └── Общая коллекция наград
```

Нижняя навигация: Главная / Материалы / Тренировка / Практика / Мой Кипр. Подготовка к экзамену — заметный маршрут с главной; также доступна из материалов. Введение — первый шаг конкретной темы, а не ещё одна вкладка верхнего уровня.

## Три оси, которые не нужно путать

1. **Уровень**: A2 / B1 / B2 — сложность и цель.
2. **Содержание**: грамматика / лексика / глаголы — что изучать.
3. **Режим**: тренировка / самостоятельная практика — как работать.

Подготовка к экзамену использует то же содержание через четыре навыка. Не нужно создавать три независимые копии библиотеки для экзамена, грамматики и тренировки. Одна карточка имеет ID, теги навыков, тем и уровней применимости. Не у всех материалов один исключительный уровень: базовые правила полезны и позднее.

## Примеры переходов

- Главная B1 → материалы → грамматика B1 → тема → объяснение → тренировка → результат → коллекция / продолжить.
- Главная B2 → материалы → повторить артикли A2 → объяснение A2 → отработка в имеющемся прототипе A2 → назад. Выбранный уровень B2 сохраняется.
- Подготовка A2 → чтение → выбранный ответ → не понимаю правило → грамматика → вернуться к тому же заданию. Выбор ответа сохраняется.
- Материалы → глаголы → γράφω → как выбрать время → грамматика → тренировать формы.
- Материалы → лексика → в кафе → выражение с έναν καφέ → винительный / глаголы / отработка.
- Любой уровень → практика → глаголы → пользователь сам задаёт упражнение. Текущая практика основного приложения сохраняет своё поведение.

## Существующий прототип A2

Он остаётся основой, без копирования нового курса. В прототип карты добавлены переходы в него:

- `../a2-cards/?view=training` — уже существующая тренировка A2;
- `../a2-cards/?view=practice&topic=articles` — существующая практика выбранной темы;
- из шапки карточек — обратная ссылка на карту и выбор уровня.

В навигационном макете есть короткие демонстрационные задания, чтобы проверить сам переход «экран → экран → результат». Они используют те же данные карточек A2, а не новый набор. B1/B2 представлены примерами интерфейса и одной демонстрационной карточкой, не готовыми курсами и не проверенными экзаменационными вариантами.

## Счётчики

В исходном прототипе исправлено «0 карточек пройдено» на **«0 из 6 карточек пройдено»**. В теме шесть карточек: два объяснения и четыре упражнения. Объяснение отмечается по явному нажатию перехода после чтения. Упражнение отмечается при проверке; повтор не увеличивает число уникальных пройденных карточек. «Пройдено» означает выполнение шага, а не доказанное владение темой. Точность ответа хранится и показывается отдельно.

Грамматические карточки A2 в обоих прототипах читают общие отметки из прежнего хранилища. Демо-сессии карты пока имеют отдельные результаты; это явно прототип механики, не полная интеграция статистики.

## Визуальная идея и награды

Первоначальный зелёный был спокойным акцентом; он не был взят с флага Кипра. Теперь направление осознанно связано с современным Кипром: оливковый акцент, медные детали, светлый камень. Это палитра проекта, а не буквальное воспроизведение флага.

Общая цифровая коллекция «Мой Кипр», сохраняющаяся между уровнями:

- оливковая веточка — первое объяснение и завершённая отработка грамматики;
- стаканчик кофе на вынос — первая завершённая тренировка;
- бутылочка Коммандарии — три завершённые сессии.

Это предварительные условия для проверки механики. Финальные награды — небольшие предметы в одном иллюстративном стиле, не отдельный визуальный мир для каждого уровня. В текущем прототипе эмодзи служат временными обозначениями. Не приравнивать число наград к готовности сдавать экзамен. Основную систему наград приложения этот макет пока не меняет.

## Пределы макета

Кликабельный HTML-макет с мобильной логикой, а не собранное нативное приложение. Работает выбор уровня, переходы, базовые карточки и обратный переход к заданию с ответом. Регистрация, полноценные курсы B1/B2, экзаменационная диагностика и синхронизация между устройствами не реализованы.
